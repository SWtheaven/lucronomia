# LucronomIA Lean

Official public pages for **LucronomIA Lean**, a local dashboard used to monitor content metrics, save checkpoints and support editorial decisions across supported social platforms.

## Public pages

After GitHub Pages is enabled for the repository:

- Home: `https://swtheaven.github.io/lucronomia/`
- Privacy Policy: `https://swtheaven.github.io/lucronomia/privacy.html`
- Terms of Service: `https://swtheaven.github.io/lucronomia/terms.html`

## Repository files

- `index.html` — official application information page
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `styles.css` — visual styles
- `.nojekyll` — serves the static files directly

The public website does not contain platform credentials, OAuth tokens or private dashboard data.
