Terms of Service

Last updated: August 20, 2026

1. Purpose

LucronomIA Lean is a local dashboard used to monitor content metrics, compare platform performance, save measurement checkpoints and support editorial decisions for the LucronomIA content operation.

2. Platform connections

When the user connects a supported social platform, LucronomIA Lean uses that platform's official authorization process and APIs. Access is limited by the permissions granted by the user and by the data made available by the platform.

3. Read-only use

The intended metrics integrations are read-only. The app does not need to publish, edit or delete social media posts to perform its analytics function.

4. Data accuracy and availability

Metrics are supplied by third-party platforms. LucronomIA Lean does not guarantee that every metric will be available at all times. When a platform does not return a value, the app should treat the metric as unavailable rather than inventing a result.

5. Local operation

The dashboard is designed to run locally on the user's computer. The user is responsible for keeping local backups and for protecting any credentials or authorization files stored on that computer.

6. Third-party terms

Use of YouTube, TikTok, Instagram or any other connected service remains subject to the respective platform's own terms, developer policies and API availability.

7. Changes

These terms may be updated when the app's functionality, integrations or operating model changes. The latest version will be published on this page.
