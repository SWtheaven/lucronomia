# LucronomIA — Fluxo de Produção no CapCut

## Objetivo

Transformar cada pauta aprovada em uma ordem de produção executável com o mínimo possível de interpretação por parte da equipe.

## Ferramenta padrão

**CapCut** é a ferramenta operacional padrão para criação e edição dos conteúdos da LucronomIA.

## Antes de abrir o projeto

Confirmar que o briefing contém:

- objetivo da peça;
- plataforma;
- formato;
- número de slides ou cenas;
- texto aprovado;
- assets necessários;
- identidade visual de referência;
- CTA;
- instrução de exportação.

Se algum dado factual necessário estiver ausente, não inventar.

## Formatos-base

### Carrossel Instagram

- proporção: **4:5**
- resolução: **1080 × 1350 px** por card
- exportação: PNG ou JPG em alta qualidade

### Reels / TikTok / Shorts

- proporção: **9:16**
- resolução: **1080 × 1920 px**
- manter textos importantes dentro da área segura central para evitar sobreposição com interface da plataforma

## Estrutura de projeto

### 1. Criar projeto

1. Abrir o CapCut.
2. Criar um novo projeto.
3. Definir a proporção/resolução correta antes de montar o layout.
4. Importar somente assets previstos no briefing.

### 2. Criar a base visual

1. Inserir o fundo aprovado.
2. Ajustar escala sem deformar.
3. Verificar se o fundo não compete com o texto.
4. Aplicar escurecimento/desfoque apenas quando necessário para leitura.

### 3. Inserir o logo

1. Usar o asset oficial.
2. Manter proporção.
3. Posicionar conforme o briefing.
4. Em carrosséis, copiar o mesmo logo para os demais cards em vez de reconstruí-lo.

### 4. Inserir headline

1. Copiar o texto exatamente como aprovado.
2. Aplicar a fonte principal da baseline.
3. Ajustar quebras de linha deliberadamente.
4. Garantir leitura rápida em tela pequena.
5. Evitar reduzir demais a fonte apenas para encaixar texto excessivo; nesse caso, devolver para revisão.

### 5. Inserir texto secundário

1. Usar a família sans-serif secundária.
2. Manter contraste suficiente.
3. Não adicionar informação para preencher espaço.
4. Preservar respiro entre headline e explicação.

### 6. Aplicar destaques

Podem ser utilizados quando previstos:

- verde elétrico;
- marca-texto;
- outline;
- glow controlado;
- bullets verdes.

O efeito nunca deve prejudicar a legibilidade.

### 7. Elementos tecnológicos

Usar grids, circuitos, linhas técnicas e códigos em baixa opacidade como apoio visual.

Não adicionar robôs, foguetes, dinheiro, ícones 3D ou imagens genéricas sem função editorial.

## Vídeos: animação e ritmo

Quando o conteúdo for vídeo:

1. Definir duração de cada cena no briefing.
2. Usar animações simples e coerentes.
3. Evitar transições diferentes em cada corte.
4. Priorizar leitura do texto sobre efeito visual.
5. Sincronizar mudanças de cena com narração ou batida quando isso melhorar o ritmo.
6. Conferir o vídeo sem som para garantir que a informação essencial ainda seja compreensível quando necessário.

## Áudio

- trilha deve apoiar, não competir com narração;
- evitar volume excessivo;
- usar áudio permitido/licenciado pela plataforma ou biblioteca disponível;
- não escolher trilha apenas por tendência se ela conflitar com o tom da marca.

## Revisão visual obrigatória

Antes de exportar:

- conferir ortografia;
- conferir ordem dos slides/cenas;
- conferir logo;
- conferir margens;
- conferir alinhamentos;
- conferir contraste;
- conferir consistência de fontes;
- conferir intensidade de glow/efeitos;
- visualizar em escala próxima à de um celular;
- confirmar que nenhum dado foi adicionado sem aprovação.

## Exportação

### Carrossel

1. Exportar cada card em **1080 × 1350 px**.
2. Numerar os arquivos na ordem correta: `01`, `02`, `03` etc.
3. Conferir todos lado a lado antes da publicação.

### Vídeo vertical

1. Exportar em **1080 × 1920 px**.
2. Usar qualidade alta.
3. Revisar o arquivo exportado do início ao fim.
4. Conferir se não há frames pretos, cortes de texto ou áudio desalinhado.

## Checklist de entrega

- [ ] Briefing seguido sem alteração editorial não autorizada.
- [ ] Formato correto para a plataforma.
- [ ] Logo oficial.
- [ ] Identidade visual consistente.
- [ ] Texto igual ao aprovado.
- [ ] Nenhuma informação inventada.
- [ ] Legibilidade conferida no celular.
- [ ] Exportação em alta qualidade.
- [ ] Arquivos na ordem correta.
- [ ] Peça enviada para aprovação antes da publicação quando o fluxo exigir.

## Regra de escalonamento

Quando houver dúvida entre “preencher” e “deixar vazio”, deixar vazio e pedir revisão.

Quando houver dúvida factual, interromper a execução e pedir validação editorial.
