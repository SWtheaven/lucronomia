## Regra de manutenção

Sempre que um conteúdo for aprovado ou publicado:

1. adicionar/atualizar o código;
2. registrar formato;
3. registrar status;
4. registrar data somente quando confirmada;
5. não criar título, métrica ou descrição ausente da fonte aprovada;
6. quando existir documentação específica, adicionar link para o arquivo correspondente.
