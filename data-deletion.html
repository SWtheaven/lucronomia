Data Deletion Instructions

Last updated: August 21, 2026

1. Disconnect the platform

Open LucronomIA Lean, go to Settings, and use the Disconnect action for the connected platform. This removes the locally stored authorization used by the dashboard to request new platform data.

2. Revoke platform authorization

You may also revoke LucronomIA Lean directly from the connected platform's app or authorization settings. After revocation, LucronomIA Lean can no longer request new data with that authorization.

3. Delete local dashboard data

LucronomIA Lean is a local-first application. To remove saved dashboard data, use the application's delete/reset or backup/restore controls where available, and remove the local application data from the computer or browser where the dashboard is running.

4. What is retained by this public website

This public website does not store social-platform access tokens, refresh tokens, video analytics, or connected-account credentials.
